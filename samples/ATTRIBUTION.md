# Sample Attribution

Provenance for every committed clip in `samples/`. One entry per file, no exceptions —
a clip without an entry gets removed rather than researched after the fact.

Synthetic fixtures from `rfwhisper/samples/synth.py` are generated on demand and are not
listed here; they are covered by the project's GPLv3-or-later licence like the rest of
the source.

## Format

Copy this block per clip:

```
### samples/<path>.wav

- **Contributor:** <callsign or "anonymous">
- **Date / time (UTC):** <YYYY-MM-DD HH:MM>
- **Band / frequency:** <e.g. 40m, 7.185 MHz>
- **Mode:** <SSB / CW / FT8 / NBFM / ...>
- **Receiver:** <rig or SDR>
- **Antenna:** <antenna, height, orientation>
- **Dominant noise:** <believed source, e.g. neighbour solar inverter>
- **Licence:** <CC BY 4.0 | CC0 1.0>
- **Consent:** <for QSO recordings: confirmation the other operator agreed>
- **Notes:** <anything a listener should know>
```
